# Ejercicio 1: Par o impar
## Problema
Determinar si un número entero es par o impar.
## Entrada
Un número entero (n).
## Proceso
1. Leer número n
2. Si n MOD 2 == 0 entonces:
3.    Escribir "El número es Par"
4. Sino:
5.    Escribir "El número es Impar"
6. FinSi
## Salida
Indicar si el número es par o impar.
## Pruebas
| Entrada | Resultado esperado |
| :--- | :--- |
| 8 | Par |
| 7 | Impar |
| 10 | Par |
