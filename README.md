## Lo que aprendí
Un repositorio sirve para reunir los archivos de un proyecto y conservar su historial de cambios.

Un commit sirve para registrar un conjunto de cambios acompañado de un mensaje descriptivo.

Una rama sirve para trabajar en una línea separada y preparar modificaciones sin afectar la versión principal.
